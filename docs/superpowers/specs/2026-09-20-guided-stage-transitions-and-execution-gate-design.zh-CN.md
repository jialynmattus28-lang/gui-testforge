# 分步自动跳转与执行准入设计

[English](2026-09-20-guided-stage-transitions-and-execution-gate-design.md) | [简体中文](2026-09-20-guided-stage-transitions-and-execution-gate-design.zh-CN.md)

**日期：** 2026-09-20
**状态：** 已实现并通过验证

## 1. 目标

让 Studio 的六步流程在完成当前工作后自动前进，同时保留明确的人工导航能力。进入 **Run and Trace** 并不代表已经可以执行：只有被测程序已经运行，并且项目专用 GUI Driver 已提供且校验通过，才能开始测试。

## 2. 方案比较

1. **推荐方案：自动前进，同时保留“下一步”。** 当前步骤成功完成后自动进入下一步；每个已完成步骤也提供“下一步”按钮；Run and Trace 单独设置执行准入条件。
2. 只允许手工点击“下一步”。行为容易理解，但五分钟 Demo 会产生较多重复操作。
3. 只允许自动前进。操作最快，但用户不容易停留查看每个阶段的边界和结果。

选择第一种方案，同时兼顾首次使用者的引导体验和专业用户的主动控制。

## 3. 页面跳转规则

每个步骤只有一个确定性的完成条件：

| 步骤 | 完成条件 | 自动进入 |
| --- | --- | --- |
| Requirements | 已确认需求 | Test IR Design |
| Test IR Design | 已生成一组通过校验的提案 | Human Review |
| Human Review | 每条用例均有人工裁决 | Freeze Asset |
| Freeze Asset | 已冻结审批通过的 Test IR 资产 | Compile |
| Compile | 原生 Playwright 脚本编译并通过用例发现 | Run and Trace |
| Run and Trace | 原生测试执行结束 | 无 |

除最后一步外，每个页面都显示“下一步”按钮。在当前步骤未完成前按钮保持禁用。用户仍可通过顶部步骤导航返回任意已经解锁的页面。

## 4. 人工审核

Human Review 保留逐条审批、拒绝、手工修改和 AI 共创功能，并增加：

- **审批所有：** 对当前全部 Test IR 明确记录人工审批，包括尚未处理或此前被拒绝的用例。这是确定性的批量工作流操作，不属于 AI 决策。
- **下一步：冻结资产：** 仅在每条用例都有当前人工裁决后启用。

最后一条未处理用例完成裁决，或“审批所有”执行成功后，系统自动进入 Freeze Asset。用户返回已完成的审核页面时，仍可使用手工“下一步”。

## 5. 执行准入

编译阶段继续保持不依赖 GUI、被测地址和已实现 Driver。编译成功后进入 Run and Trace，但状态显示为 **等待被测程序和 GUI Driver**。

只有以下两项都已提供并通过校验，运行按钮才可点击：

1. **被测程序 URL：** 用户输入的、格式有效的 HTTP 或 HTTPS 地址。
2. **GUI Driver：** 用户选择的 `.mjs` 文件，并且该文件导出符合约定的 `createDriver` 工厂。

Studio 将所选 Driver 保存到隔离工作目录，校验 Driver 接口，并且只在公开状态中保留不含敏感信息的就绪信息。更换 URL 或 Driver 后，之前的运行结果失效。

一键 Demo 继续包含预制应用和 Driver，但不再默认启用。用户必须明确点击 **Use bundled demo**，系统才同时配置这两项。这样既保留五分钟体验，也不会让真实交接流程产生误解。

## 6. 错误处理

- URL 格式错误或协议不支持：显示明确错误，运行按钮保持禁用。
- Driver 缺失、扩展名不是 `.mjs` 或导出不符合约定：显示校验错误，运行按钮保持禁用。
- 被测程序无法访问：不得产生通过结果，由原生 Playwright 报告连接失败。
- 更换 Driver：执行前重新校验，并清除旧的执行结果。
- 无论执行条件是否就绪，编译结果都保持为 `COMPILED / NOT_EVALUATED`。

## 7. 测试

- 界面测试验证自动跳转以及“下一步”的启用与禁用状态。
- API 测试验证“审批所有”和执行配置校验。
- 端到端 Demo 必须先明确选择 Use bundled demo，运行按钮才可启用。
- 既有集成测试继续证明：没有 GUI 和已实现 Driver，也可以完成编译和用例发现。

## 8. 验收标准

- 第 1 至第 5 步完成后自动进入下一步。
- 已完成步骤提供可用的手工“下一步”。
- “审批所有”会为全部当前用例明确记录人工审批。
- 编译后可以进入 Run and Trace，但缺少任一交接输入时不能运行。
- 内置被测程序和 Driver 只能通过明确的 Demo 操作启用。
- 页面跳转、批量审批、准入校验、测试执行和结果判定均无 AI 参与。
