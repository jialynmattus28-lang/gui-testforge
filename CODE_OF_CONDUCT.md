# Code of Conduct

[English](CODE_OF_CONDUCT.md) | [简体中文](CODE_OF_CONDUCT.zh-CN.md)

We are committed to a respectful, inclusive, and technically rigorous community. Be constructive, focus criticism on ideas and code, respect privacy, and do not harass or discriminate against participants.

Project maintainers may remove content or participation that violates these expectations. Report conduct concerns privately through the repository maintainers or GitHub reporting tools.
