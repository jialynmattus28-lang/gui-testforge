# GUI TestForge Support

[English](SUPPORT.md) | [简体中文](SUPPORT.zh-CN.md)

- Use **GitHub Discussions** for setup questions, integration guidance, and design conversations.
- Open a **Bug report** issue for reproducible defects. Include the operating system, commit or release, workflow stage, expected behavior, and actual behavior.
- Open a **Feature request** issue for a focused product proposal.
- Do not disclose vulnerabilities, credentials, customer data, or private PRDs in Discussions or Issues. Use GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md).

Support is community-based. Public-preview releases do not include a service-level agreement.
